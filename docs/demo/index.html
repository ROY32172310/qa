Run it on your page

One command. Eight phone variants. No test file.

python -m pip install ego-webqa ego-webqa install-browser then ego-webqa https://your-preview.example

This report covers deterministic coarse checks for multi-device geometry and basic delivery use. Business flows, cross-browser behavior, security, and accessibility compliance require separate verification.
